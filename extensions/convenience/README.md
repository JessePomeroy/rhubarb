# Convenience commands

- `/lg` browses changed files and staged/unstaged diffs without invoking a shell.
- `/pr` displays the current branch's GitHub pull request through authenticated GitHub CLI.
- `/copy-all` copies all user and assistant messages on the active session branch.

Clipboard backends are selected by platform: `wl-copy`, `xclip`, or `xsel` on Linux; `pbcopy` on macOS; and `clip.exe` on Windows.
