# UI customization

Installs a lowercase `rhubarb` Catppuccin gradient header and a two-line dashboard footer.

The footer shows directory, provider/model, thinking level, context utilization, context window, session cost, recent output speed, Git branch, changed-file count, and pull request when GitHub CLI is available. Extension status rows remain visible below it.

Git data refreshes after shell and file-mutating tools rather than through continuous polling.
